# SV-analysis
This repository contains the shell, Perl, and R scripts used in the article “**Performance evaluation of structural variation detection using DNBSEQ whole-genome sequencing**”.

# Directory structure
step1.sv_calling.sh
    shell script for the detection of structural variants (SVs).
step2.sv_eval.sh
    shell script for evalutaion of SVs against a benchmark to assess performance.
step3.sv_integration.sh
    shell script for integrating SV sets from DNBSEQ or Illumina datasets.
step4.figures
    the Perl and R scripts used to generate Figure2 to Figure5.
